## 项目概述

### 项目背景

Open物品收纳是一款个人物品整理记录的安卓应用，目标是帮助用户记录物品信息、位置，方便以后找物品，以及方便搜索查看、汰换旧物品。

### 核心功能

1. **住处管理**：物品归属于住处，支持多住处切换和筛选
2. **物品记录**：记录物品名称、注释、大小分类、类型、照片、购入时间、过期日期、位置
3. **搜索筛选**：支持全文搜索和字段筛选，可保存筛选快捷入口
4. **搬家模式**：批量迁移物品到新住处
5. **数据备份**：支持SQLite数据库和照片的导出导入

### 技术选型

- **最低支持版本**：Android 10（API 29）
- **开发语言**：Kotlin
- **UI框架**：Jetpack Compose（Material Design 3）
- **架构模式**：MVVM + Repository
- **数据库**：Room（SQLite）
- **依赖注入**：Hilt
- **异步处理**：Coroutines + Flow
- **图片加载**：Coil
- **照片压缩**：自研压缩算法

### 核心设计原则

1. **Repository抽象**：`ItemRepository`是接口，第一版用`SQLiteItemRepository`实现，第二版可替换为`OneDriveItemRepository`
2. **单向数据流**：UI → ViewModel → Repository → DataSource
3. **依赖注入**：使用Hilt管理依赖
4. **响应式**：使用Flow/StateFlow进行数据观察

## 数据模型设计

### 核心实体

#### 1. 住处（Residence）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键，自增 |
| name | String | 住处名称，如"北京的家" |
| createdAt | Long | 创建时间戳 |

#### 2. 物品（Item）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键，自增 |
| residenceId | Long | 所属住处ID（外键） |
| name | String | 物品名称 |
| note | String? | 注释（可选） |
| sizeCategory | Enum | 大小分类：FURNITURE（家具）、LARGE（大件）、SMALL（小件） |
| type | String? | 类型（可选），如"电子产品"、"书籍" |
| photoPath | String? | 照片文件路径（可选） |
| purchaseDate | Long? | 购入时间戳（可选），null表示"很久" |
| expiryDate | Long? | 过期时间戳（可选） |
| locationId | Long | 位置ID（外键） |
| createdAt | Long | 创建时间戳 |
| updatedAt | Long | 更新时间戳 |

#### 3. 位置（Location）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键，自增 |
| residenceId | Long | 所属住处ID（外键） |
| name | String | 位置名称，如"书桌抽屉" |
| isPreset | Boolean | 是否预置（"灵活"、"未设置"） |
| usageCount | Int | 使用次数（用于LRU排序） |
| lastUsedAt | Long | 最后使用时间（用于LRU排序） |

#### 4. 类型（Type）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键，自增 |
| name | String | 类型名称，如"电子产品" |
| isPreset | Boolean | 是否预置 |
| usageCount | Int | 使用次数（用于LRU排序） |
| lastUsedAt | Long | 最后使用时间（用于LRU排序） |

#### 5. 筛选快捷入口（FilterShortcut）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键，自增 |
| name | String | 快捷入口名称，如"快过期物品" |
| filterConfig | JSON | 筛选条件配置（JSON字符串） |

### 预置数据

**预置位置**（每个住处创建时自动生成）：
- 灵活（isPreset=true）
- 未设置（isPreset=true）

**预置类型**：
- 电子产品
- 书籍
- 食物
- 办公用品

**预置大小分类**：
- 家具（FURNITURE）
- 大件（LARGE）
- 小件（SMALL）

**LRU排序**：
- 位置和类型选项按LRU（最近最少使用）排序
- 保留最近使用的20条记录
- 每次使用时更新`usageCount`和`lastUsedAt`
- 排序规则：先按`lastUsedAt`降序，再按`usageCount`降序

### 数据库索引

- `Item.residenceId`：外键索引
- `Item.locationId`：外键索引
- `Item.name`：全文搜索索引（FTS）
- `Item.expiryDate`：过期筛选索引
- `Location.residenceId`：外键索引
- `Location.usageCount + lastUsedAt`：LRU排序索引
- `Type.usageCount + lastUsedAt`：LRU排序索引

## UI流程设计

### 1. 首页（物品列表）

**布局**：
- 顶部：搜索栏 + 筛选按钮 + 排序按钮
- 中部：物品列表（卡片视图，支持切换列表/网格）
- 底部：FAB（添加物品）

**功能**：
- 搜索：全文搜索（匹配名称、注释）
- 筛选：按住处、位置、类型、大小分类、过期时间等筛选
- 排序：最多3字段复合排序（如：先按位置，再按购入时间，最后按名称）
- 快捷入口：保存的筛选条件（如"快过期物品"）

**物品卡片显示**：
- 照片缩略图（如有）
- 名称
- 位置
- 过期时间（如有，显示"还有X天过期"或"已过期X天"）
- 左滑删除（需确认，可设置本次启动不再确认）

### 2. 添加/编辑物品

**进入方式**：点击FAB或物品详情中的编辑按钮

**表单字段**：
- 名称（必填，文本输入）
- 注释（可选，多行文本）
- 大小分类（必选，单选按钮：家具/大件/小件）
- 类型（可选，下拉选择，支持快速新建）
- 照片（可选，拍照或从相册选择）
- 购入时间（可选，日期选择器或"很久"选项）
- 过期日期（可选，日期选择器）
- 位置（必选，下拉选择，支持快速新建，默认带入上次选择）

**默认值带入**：
- 首次添加：使用系统默认值
- 后续添加：自动带入上次添加的"住处"、"位置"、"类型"、"大小分类"、"购入时间"

**验证**：
- 名称为空时提示
- 同名物品提示"已有X个同名物品"
- 位置未选择时提示

### 3. 物品详情（底部抽屉）

**展示内容**：
- 照片（大图）
- 名称
- 注释
- 大小分类
- 类型
- 购入时间（显示"很久"或具体日期）
- 过期日期（显示"还有X天过期"或"已过期X天"）
- 位置
- 所属住处

**交互**：
- 每个字段右侧有编辑按钮，点击进入编辑模式
- 点击字段值复制到剪贴板
- 底部有删除按钮

### 4. 搬家模式

**进入方式**：首页菜单或设置页面

**流程**：
1. 选择老住处和新住处
2. 显示老住处物品列表（默认按位置排序）
3. 支持临时筛选（按位置、类型等）
4. 滑动多选物品
5. 选择迁移方式：
   - 指定新位置：选择新住处的某个位置
   - 同位迁移：自动创建新住处的同名位置
   - 灵活迁移：设为新住处的"未设置"
6. 确认迁移

**迁移后处理**：
- 物品的`residenceId`变更为新住处
- 物品的`locationId`变更为新住处的对应位置
- 物品的`updatedAt`更新为当前时间

### 5. 设置页面

**配置项**：
- 照片压缩质量（每图最大容量，如500KB、1MB、2MB）
- 主题设置（深色/浅色/跟随系统）
- 删除确认开关
- 导出数据（SQLite + 照片ZIP包）
- 导入数据（选择ZIP包，自动处理同名住处）
- 住处管理（添加、改名、删除）
- 位置管理（查看、删除自定义位置）
- 类型管理（查看、删除自定义类型）

## 边界情况和异常处理

### 1. 数据验证

**物品名称**：
- 允许重复，但添加/编辑时提示"已有X个同名物品"
- 最大长度100字符
- 不允许为空

**位置**：
- 删除位置时，使用该位置的物品自动变为"未设置"
- 预置位置（"灵活"、"未设置"）不允许删除
- 位置名称最大长度50字符

**住处**：
- 删除住处需二次确认，删除后内部所有物品、位置、类型关联数据一并删除
- 住处名称最大长度50字符
- 不允许为空

**类型**：
- 删除类型时，使用该类型的物品类型字段变为null
- 预置类型不允许删除
- 类型名称最大长度50字符

### 2. 照片处理

**压缩策略**：
- 用户可配置每图最大容量（500KB、1MB、2MB），默认1MB
- 压缩算法：先压缩尺寸（最长边不超过1920px），再压缩质量（JPEG质量从90开始递减，直到满足大小要求）
- 存储格式：JPEG

**存储路径**：
- 应用私有目录：`/data/data/com.riverxu.itemmanager/files/photos/`
- 文件命名：`{itemId}_{timestamp}.jpg`

**异常处理**：
- 拍照失败：提示"拍照失败，请重试"
- 存储空间不足：提示"存储空间不足，请清理后重试"
- 照片损坏：显示默认占位图

### 3. 导入导出

**导出**：
- 导出格式：ZIP包，包含`database.db`（SQLite数据库）和`photos/`目录（所有照片）
- 导出路径：用户选择的目录（通过SAF）
- 导出文件名：`OpenItemManager_backup_{timestamp}.zip`

**导入**：
- 导入前验证ZIP包完整性（是否包含database.db）
- 导入时检查数据库版本兼容性
- 同名住处处理：自动改名为"{原名}新导入"
- 导入失败：提示具体错误原因

### 4. 性能优化

**列表性能**：
- 使用Paging 3分页加载，每页50条
- 照片缩略图使用Coil加载，内存缓存+磁盘缓存
- 列表项使用`LazyColumn`，避免一次性加载所有数据

**搜索性能**：
- 全文搜索使用SQLite FTS（全文搜索）扩展
- 筛选条件使用索引优化

**数据库性能**：
- 外键关联添加索引
- 定期VACUUM优化数据库

### 5. 异常场景

**数据库损坏**：
- 启动时检测数据库完整性
- 损坏时提示"数据异常，请从备份恢复"
- 提供"从备份恢复"入口

**存储权限**：
- Android 10+使用Scoped Storage，无需存储权限
- 导出/导入使用SAF（Storage Access Framework）

**内存不足**：
- 照片加载使用采样压缩
- 列表滑动时取消不可见项的照片加载
