# 物品管家Free v0.3.0

**首个公开发布版本。**

物品管家Free 是一款完全离线的个人物品整理记录应用：把家里每件东西的位置、照片和关键信息记下来，
需要时按位置、类型、标签快速找到，并提前看到哪些东西快过期、哪些该汰换或出售。

数据全部保存在手机本地，应用**不申请任何权限**，也没有任何网络访问。

---

## 本次版本

- **标签（多选）**：一件物品可同时打多个自定义标签，预置「待汰换」「待出售」
- **录入时间**：物品创建时自动记录，不可手动修改
- **最近更新位置时间**：仅在位置或住处发生变化时推进，改名称/注释/照片都不影响
- **购入时间一键填「今天」**：录入页面日期右侧新增快捷按钮
- **筛选快捷入口改为短按切换**：短按应用，再短按取消并还原到应用前的条件；
  已应用时不再显示「清除筛选」「保存为快捷入口」；删除仍在长按菜单中

## 功能一览

### 住处与位置

- 支持多个住处，随时切换、改名、删除；删除住处会一并清理其下的位置与物品
- 每个住处自带「灵活」「未设置」两个预置位置；删除位置时，其中的物品自动归入「未设置」
- 位置列表按最近使用频率排序，常用位置自动排在前面

### 物品记录

- 字段：名称、注释、大小分类（家具 / 大件 / 小件）、类型、标签、照片、购入时间、过期日期、存放位置
- 购入时间支持「很久」（不记得具体日期时），也可一键填「今天」
- 名称重复时会给出提示，避免无意中录入两遍
- 类型可随时新建，预置电子产品、书籍、食物、办公用品

### 照片

- 直接调用系统相机拍照，或从相册选择
- 六档压缩质量可选：**32 KB / 64 KB / 128 KB / 256 KB / 512 KB / 1 MB**（默认 128 KB）
- 压缩策略：最长边不超过 1920px；在设定的容量上限内自动选取画质最高的参数；
  极小目标下逐级缩小尺寸来达成；若确实无法压到目标，保存后会如实告知实际大小
- 列表与详情显示时按需采样解码，并带内存缓存，长列表滚动不会一次加载全部原图

### 标签

- 一件物品可同时拥有多个标签，录入和查看时都能随手增删
- 预置「待汰换」「待出售」，可直接用来标记准备清理的东西
- 支持添加、重命名、删除标签；重命名成已有名称时两个标签自动合并
- 删除标签只解除物品上的标记，不会影响物品本身

### 搜索、筛选与排序

- **搜索**：按名称与注释模糊匹配
- **筛选**：住处、位置、类型、标签、大小分类、过期状态（已过期 / 7 天内 / 30 天内 / 90 天内 /
  已设置过期时间 / 未设置）、购入时间区间
- **排序**：最多三个字段组合，每个字段可单独设置升序或降序、以及空值排最前还是最后
- **筛选快捷入口**：把常用的筛选与排序组合存下来。**短按应用，再短按取消**，
  取消时会还原到应用之前的状态；长按可删除

### 浏览与管理

- 列表 / 网格两种视图，随意切换
- 左滑删除，是否二次确认可自行设置
- 长按进入多选，可批量删除
- 物品详情底部抽屉：所有字段就地编辑、点击字段复制到剪贴板、一键跳转完整编辑；
  底部操作栏固定，字段再多也不用来回滚动

### 搬家模式

搬东西时最好用的功能：选定原住处与新住处 → 按位置顺序浏览物品 → 勾选要搬的 →
选择「搬到新住处的某个位置」「按同名位置搬过去」或「先放未设置，之后再归置」。

### 数据备份

- **导出**：生成一个 ZIP，内含完整数据库、全部照片和一份清单（manifest.json），
  可存到手机任意目录或网盘
- **导入**：校验备份完整性后整库恢复；若与现有住处同名会自动改名，不会覆盖
- 旧版本导出的备份也可以直接导入

### 其他设置

- 照片压缩质量
- 主题：跟随系统 / 浅色 / 深色
- 删除确认开关
- 住处、位置、类型、标签管理
- 数据统计：物品、住处、位置、类型、标签、照片数量与占用空间

## 隐私

- **不申请任何权限**：不含相机、存储、位置、通讯录等任何权限申请。
  拍照通过系统相机完成、选图使用系统照片选择器、导入导出使用系统文件选择器，
  都不需要应用自身持有权限
- **完全离线**：没有网络访问能力，应用数据不会离开你的手机
- **不参与系统备份**：已关闭 Android 自动备份与数据迁移，数据只存在于本机
  （需要备份请使用应用内的导出功能）

---

## 已知限制

- **删除不可撤销**：没有回收站，删除的物品与照片会立即清除，建议定期导出备份
- **无云同步**：不支持多设备同步，跨设备迁移请使用导出 / 导入
- **仅本机单用户**：没有账号体系，也没有分享功能
- 大量物品（数千条以上）时的滑动与搜索性能尚未充分验证
